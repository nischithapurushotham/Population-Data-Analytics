# 🌍 Population Data Analytics Project

## Overview

This project analyzes the World Bank Population Dataset using Python.

The project includes:

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Population Growth Analysis
- Data Visualization
- Linear Regression Forecasting
- Future Population Prediction
